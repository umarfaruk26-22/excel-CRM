Duplicate Detection Rules Reference

The CRM checks imported Excel rows against MySQL in the following priority order:

  1. CRM Customer Code / ID: Exact alphanumeric match (e.g. CUST-1002).
  2. Normalized Mobile: 10-digit clean digits match, ignoring leading zeros, country code +91, spaces, and hyphens.
  3. Normalized Email: Lowercased, whitespace-trimmed email comparison.

Records are never merged on customer name alone to prevent false positives for common names.
